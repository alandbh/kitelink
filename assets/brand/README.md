# Kitelink brand assets

## Logo files

| File | Purpose |
|------|---------|
| `logo/logo-positive.svg` | Primary logo (light backgrounds) |
| `logo/logo-negative.svg` | Primary logo (dark backgrounds) |
| `logo/icon-positive.svg` | App icon (color) |
| `logo/icon-negative-mono.svg` | App icon (mono / dark UI) |
| `logo/examples/*.png` | Raster previews / store exports |
| `palette.md` | Color tokens and emblem mapping |

## Notes

- Zip archives under `logo/` are ignored by git; use the extracted SVG/PNG files.
- UI should map CSS variables from `palette.md`.
- Prefer Nautilus-compatible symbolic emblems where possible.
